= Quickstart

== Installation

```bash
pip install neo4j-mcp-server
```

For a more comprehensive installation guide, see xref:installation.adoc[].


== Configuration for Aura MCP (VSCode)

To connect to Aura MCP:

. Retrieve the Aura instance ID you would like to use with Neo4j MCP, for example:
+
.Aura instance ID
image::instance-id.png[Aura instance ID]
+
. The Aura MCP URL is: `https://<INSTANCE_ID>.mcp-instances.neo4j.io`.
+
[NOTE]
====
The MCP URL is not to be confused with the connection nor the query API URLs.
Under **Instances** from the left side navigation, you can find it via the more menu **`[...]`** and **Inspect** for the instance. 
====

Create / edit `mcp.json`:

```json
{
  "servers": {
    "neo4j-mcp": {
      "type": "http",
      "url": "https://<instance-id>.mcp-instances.neo4j.io"
    }
  }
}
```


== Server configuration (VSCode)

Create / edit `mcp.json`:

```json
{
  "servers": {
    "neo4j": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "neo4j_mcp_server"],
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "password",
        "NEO4J_DATABASE": "neo4j",
        "NEO4J_READ_ONLY": "true",
        "NEO4J_TELEMETRY": "false",
        "NEO4J_LOG_LEVEL": "info",
        "NEO4J_LOG_FORMAT": "text",
        "NEO4J_SCHEMA_SAMPLE_SIZE": "100"
      }
    }
  }
}
```

See xref:configuration.adoc[] for more details.
