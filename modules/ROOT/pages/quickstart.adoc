= Quickstart

== MCP for Aura

Retrieve your instance's MCP server URL, see xref:mcp-for-aura.adoc#find-your-mcp-server-url[Find your MCP server URL].

Then add Neo4j MCP to your client's MCP configuration.
For example, in VS Code, create or edit `mcp.json`:

```json
{
  "servers": {
    "neo4j-mcp": {
      "type": "http",
      "url": "https://<instance-id>.mcp-instances.neo4j.io"
    }
  }
}
```

See xref:client-configuration.adoc[] for other client-specific configuration.


== Self hosted

=== Installation

```bash
pip install neo4j-mcp-server
```

For a more comprehensive installation guide, see xref:installation.adoc[].

=== Configuration

Add Neo4j MCP to your client's MCP configuration. For example, in VS Code, create or edit `mcp.json`:

[NOTE]
====
On some systems the Python 3 interpreter is named `python3` instead of `python`
Use whichever is available in your environment.
====

```json
{
  "servers": {
    "neo4j": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "neo4j_mcp_server"],
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "password",
        "NEO4J_DATABASE": "neo4j",
        "NEO4J_READ_ONLY": "true",
        "NEO4J_TELEMETRY": "false",
        "NEO4J_LOG_LEVEL": "info",
        "NEO4J_LOG_FORMAT": "text",
        "NEO4J_SCHEMA_SAMPLE_SIZE": "100"
      }
    }
  }
}
```

See xref:client-configuration.adoc[] for other client-specific configuration and xref:configuration.adoc[] for the full list of configuration options.
