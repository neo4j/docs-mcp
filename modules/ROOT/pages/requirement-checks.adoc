[[requirement-checks]]
= Requirement checks
:page-aliases: startup-checks.adoc

The server checks the database requirements when it processes the MCP `initialize` request.
These checks are not startup pre-flight checks.

== Required checks

During `initialize`, the server verifies:

* A valid connection to the target Neo4j instance.
* The ability to execute queries.
* The presence of the APOC plugin, including its `meta` component.

If the database is unreachable, the configuration is invalid, or APOC is missing, the `initialize` request fails with a descriptive error.
For a missing APOC `meta` component, install the APOC plugin and ensure it includes the `meta` component.

The checks apply to both transport modes.
In STDIO mode, the URI, credentials, and database are configured on the server.
In HTTP mode, the URI, credentials, and database are selected for each request.
See xref:configuration.adoc#transport-modes[Transport modes] and xref:http-mode.adoc[].

[[gds-requirement]]
== GDS requirement

The Graph Data Science (GDS) library is optional.
If GDS is not found, the server logs a message and continues working.
GDS-specific tooling, such as `list-gds-procedures`, will not work without GDS, but the other tools remain available.
