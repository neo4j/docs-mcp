[[configuration]]
= STDIO configuration


STDIO mode requires `NEO4J_MCP_URI`, `NEO4J_MCP_USERNAME`, `NEO4J_MCP_PASSWORD`, and `NEO4J_MCP_DATABASE` (or their CLI equivalents).
Provide the database explicitly with `NEO4J_MCP_DATABASE` or `--database`.
Connectivity, query execution, and APOC requirements are checked when the MCP handshake request (`initialize` or `server/discover`) is processed.

Environment variables and equivalent command-line flags for STDIO mode:

[cols="4*", options="header"]
|===
| Variable | Equivalent command-line flag | Description | Default
| `NEO4J_MCP_USERNAME` | `--username` | Neo4j username (STDIO mode only) | _Required for STDIO_
| `NEO4J_MCP_PASSWORD` | `--password` | Neo4j password (STDIO mode only) | _Required for STDIO_
|===


== General configuration

The following environment variables and equivalent command-line flags are general configuration options:

[cols="4*", options="header"]
|===
| Variable | Equivalent command-line flag | Description | Default
| `NEO4J_MCP_URI` | `--uri` | Connection URI; required for STDIO and provided per request in HTTP | _Required for STDIO; unset for HTTP_
| `NEO4J_MCP_DATABASE` | `--database` | Database name; required for STDIO and selected in the HTTP URL | _Required for STDIO; unset for HTTP_
| `NEO4J_MCP_READ_ONLY` | `--read-only` | Set to `true` to disable write tools (see xref:tools.adoc#_readonly_mode[Readonly mode]) | `false`
| `NEO4J_MCP_TELEMETRY` | `--telemetry` | Set to `false` to disable telemetry (see xref:telemetry.adoc[]) | `true`
| `NEO4J_MCP_LOG_LEVEL` | `--log-level` | Log level (see xref:logging.adoc[]) | `info`
| `NEO4J_MCP_LOG_FORMAT` | `--log-format` | Log output format: `text` or `json` (see xref:logging.adoc#_log_formats[Log formats]) | `text`
| `NEO4J_MCP_SCHEMA_SAMPLE_SIZE` | `--schema-sample-size` | Number of nodes to sample for schema inference | `100`
| `NEO4J_MCP_TRANSPORT_MODE` | `--transport-mode` | Transport mode: `stdio` or `http` | `stdio`
| `NEO4J_MCP_TOOLS` | `--tools` | Comma-separated list of tools advertised by the server; see xref:tools.adoc#_tool_filtering[Tool filtering] | All four tools
| `NEO4J_MCP_REQUEST_TIMEOUT` | `--request-timeout` | Maximum time allowed for an MCP request; specify a number followed by a time unit, such as `45s` or `5m` | `3m` (maximum `30m`)
|===

[[request-timeout]]
== Request timeout

MCP requests, including tool calls and the handshake, are bounded by the configured timeout.
Set `NEO4J_MCP_REQUEST_TIMEOUT` or `--request-timeout` as a number followed by a time unit:

* `ms` for milliseconds, for example `500ms`
* `s` for seconds, for example `45s`
* `m` for minutes, for example `5m`

You can combine units, for example `1m30s`.
The default is `3m` and the maximum is `30m`.
See xref:http-mode.adoc#request-timeout-header[`X-Neo4j-MCP-Request-Timeout`].
