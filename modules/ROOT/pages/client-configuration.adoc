= Client configuration

== Claude Code configuration

Add the server with the `claude mcp add` command.
See link:https://code.claude.com/docs/en/mcp[Connect Claude Code to tools via MCP] for more details.

[.tabbed-example]
====
[.include-with-MCP-for-Aura]
=====
include::partial$note-find-aura-url.adoc[]

[source, bash]
----
claude mcp add --transport http neo4j-mcp https://<instance-id>.mcp-instances.neo4j.io
----
=====
[.include-with-STDIO-with-executable]
=====
include::partial$note-stdio-executable.adoc[]

[source, bash]
----
claude mcp add neo4j-mcp \
  --env NEO4J_URI=bolt://localhost:7687 \
  --env NEO4J_USERNAME=neo4j \
  --env NEO4J_PASSWORD=password \
  --env NEO4J_DATABASE=neo4j \
  --env NEO4J_READ_ONLY=true \
  -- neo4j-mcp
----
=====
[.include-with-STDIO-with-PyPI]
=====
include::partial$note-stdio-pypi.adoc[]

[source, bash]
----
claude mcp add neo4j-mcp \
  --env NEO4J_URI=bolt://localhost:7687 \
  --env NEO4J_USERNAME=neo4j \
  --env NEO4J_PASSWORD=password \
  --env NEO4J_DATABASE=neo4j \
  --env NEO4J_READ_ONLY=true \
  -- python -m neo4j_mcp_server
----
=====
====

Alternatively, edit the `.mcp.json` file in your project root directly.
This uses the same format as the xref:_claude_desktop_configuration[Claude Desktop] `mcpServers` configuration below.


== VSCode configuration

Create / edit _mcp.json_:

[.tabbed-example]
====
[.include-with-MCP-for-Aura]
=====
include::partial$note-find-aura-url.adoc[]

[source, json]
----
{
  "servers": {
    "neo4j-mcp": {
      "type": "http",
      "url": "https://<instance-id>.mcp-instances.neo4j.io"
    }
  }
}
----
=====
[.include-with-STDIO-with-executable]
=====
include::partial$note-stdio-executable.adoc[]

[source, json]
----
{
  "servers": {
    "neo4j-mcp": {
      "type": "stdio",
      "command": "neo4j-mcp",
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "password",
        "NEO4J_DATABASE": "neo4j",
        "NEO4J_READ_ONLY": "true",
        "NEO4J_TELEMETRY": "false",
        "NEO4J_LOG_LEVEL": "info",
        "NEO4J_LOG_FORMAT": "text",
        "NEO4J_SCHEMA_SAMPLE_SIZE": "100"
      }
    }
  }
}
----
=====
[.include-with-STDIO-with-PyPI]
=====
include::partial$note-stdio-pypi.adoc[]

[source, json]
----
{
  "servers": {
    "neo4j-mcp": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "neo4j_mcp_server"],
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "password",
        "NEO4J_DATABASE": "neo4j",
        "NEO4J_READ_ONLY": "true",
        "NEO4J_TELEMETRY": "false",
        "NEO4J_LOG_LEVEL": "info",
        "NEO4J_LOG_FORMAT": "text",
        "NEO4J_SCHEMA_SAMPLE_SIZE": "100"
      }
    }
  }
}
----

== Claude Desktop configuration

Configure Claude for desktop for all MCP servers you want to use.
Open your Claude for desktop App configuration in a text editor.
Find the files at:

- (MacOS/Linux) `~/Library/Application Support/Claude/claude_desktop_config.json`
- (Windows) `$env:AppData\Claude\claude_desktop_config.json`

Make sure to create the file if it doesn't exist.

Add Neo4j MCP under the `mcpServers` key:

[.tabbed-example]
====
[.include-with-MCP-for-Aura]
=====
include::partial$note-find-aura-url.adoc[]

[NOTE]
======
This requires `npx` to be available on your system, which is included with Node.js.
See link:https://nodejs.org/en/download[Download Node.js] for installation instructions.
======

[source, json]
----
{
  "mcpServers": {
    "neo4j-mcp": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://<instance-id>.mcp-instances.neo4j.io"
      ]
    }
  }
}
----
=====
